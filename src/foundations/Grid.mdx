## Columns

The reference grid layouts use fluid column-count presets (12/6/5/3/2 columns,
"auto" sizing) rather than fixed pixel column widths — build layouts with
CSS Grid / Tailwind's `grid-cols-*` utilities directly (`grid grid-cols-12
gap-6`) rather than a dedicated Column component.

## Implementation notes

Use the `Container` component rather than reproducing these values by hand:

```tsx
<Container>
  <PageContent />
</Container>
```

From the reference design file's own "Grid layouts" page. Two data points are
directly confirmed: at a 1440px viewport the container is 1280px wide (80px
side margin); at 1600px it's 1440px wide (still 80px). Tablet (768px) and
mobile (375px) go full-bleed — no container margin, just inner padding.
