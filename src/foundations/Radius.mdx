## Implementation notes

Available as `rounded-mo-sm`, `rounded-mo-md`, `rounded-mo-lg` and
`rounded-mo-full`. They are `theme.extend`, so they **add to** Tailwind's stock
scale rather than replacing it — `rounded-lg` and `rounded-none` still work.

Two things worth knowing about pills:

- **`rounded-full` and `rounded-mo-full` are not the same value.** Tailwind v4
  computes `rounded-full` as `calc(infinity * 1px)` — measured at 16,777,216px
  — while `mo-full` is 9999px. Both fully round any realistic element, so the
  difference is invisible in practice, but they are not interchangeable
  literals.
- Most pills in the component library use plain `rounded-full` (19 component files);
  `rounded-mo-full` appears in 7 places. Either renders identically.

Values derive from `tokens.mjs`, so a change there reaches this page without
editing it — the lesson from Typography.mdx, which hardcoded a token name and
blanked when it was retired. This page previously hardcoded `mo-sm` as 8px in
prose and kept saying so for the whole time the token was 12px, with a 12px
swatch rendering directly beneath the claim.
