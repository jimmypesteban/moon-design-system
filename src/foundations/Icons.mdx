## Using a custom icon in code

Lucide icons are components — import them from the curated set, never from
`lucide-react` directly:

```tsx
import { Check } from 'mosaic-design-system/icons';

<Check size={24} color="#B82431" />
```

The custom ones are SVGs rather than components, so they are rendered by name:

```tsx
import { CustomIcon } from 'mosaic-design-system';

<CustomIcon name="bot" size={32} color="#B82431" />
```

`name` is any Custom entry in the gallery above, `size` is pixels (default 24),
and `color` applies through `currentColor` — flags and logos that ship their own
colours ignore it.

The two are separate because a lucide icon is a typed, tree-shakeable component
and a custom one is raw SVG markup. Reaching for the right one matters: if a
concept is in the Custom list, use it rather than substituting a lucide icon
that looks close.

## Implementation notes

Most concepts map onto **[Lucide](https://lucide.dev) icons** (the "Lucide"
category), curated in `icons.ts` — import from `mosaic-design-system`, not
`lucide-react` directly, so the set used across apps stays a deliberate,
documented list in one outline style. Concepts lucide has no equivalent
for — education-domain modes, the product bot — are **custom to Mosaic**
(the "Custom" category): real SVG artwork in `src/customIcons.ts`, rendered
via `<CustomIcon name="..." />`. Add to `icons.ts` when a component needs a
lucide icon that isn't listed yet; add real artwork to `customIcons.ts`
(don't force-fit a lucide icon) when it needs a custom one.
