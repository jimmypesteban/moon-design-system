## Usage

- **`mo-xs` / `mo-sm`**: subtle depth for inline elements (dropdown items, small cards)
- **`mo-md` / `mo-lg`**: standard elevated surfaces (`Card`, dropdown panels)
- **`mo-xl` / `mo-2xl` / `mo-3xl`**: high-elevation surfaces (modals, popovers)
- **`mo-button`**: the specific shadow used on elevated buttons in the source design system
- **`mo-popup`**: the specific 3-layer shadow used on popups/tooltips

## Implementation notes

Available as Tailwind utilities: `shadow-mo-sm`, `shadow-mo-lg`, etc. Base
color is a neutral `#101828` at varying opacity, not `mo-black` — shadows
read as neutral depth cues rather than brand color.
