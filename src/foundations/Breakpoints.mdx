## Scale

Every breakpoint is **min-width**: `md:flex` means *flex from 768px upward*,
and applies at every larger size too. So styles cascade up, and the unprefixed
value is the phone case. There is no max-width prefix in this system — design
the narrow layout first, then add prefixes to widen it.

## What actually gets used

Counted across `apps/` and `packages/`, so you can tell a live breakpoint from
a theoretical one:

`sm:` carries most of the responsive work and `2xl:` is close to unused — worth
knowing before you reach for the extremes. Counts are a snapshot, not derived,
so treat them as a rough shape rather than a live figure.

## Implementation notes

Moon UI uses Tailwind's default breakpoint scale as-is — no app has needed
to override it at the brand-token level.

A consuming app may define additional screens of its own, but those are
**app-specific, not part of this shared base layer** — a component shared
between two apps should step its layout only at the widths this scale names,
or it will change shape at different points depending where it renders.
Reach for the stock scale unless you are inside an app that defines its own
ramp and matching it on purpose.
